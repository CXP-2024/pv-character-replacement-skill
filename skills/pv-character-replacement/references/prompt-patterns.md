# 生图 prompt：明确职责和可核对的变化

按需取用模板，替换占位内容；不要把所有模板一次塞进模型。生图工具参数以当前实际可用能力为准，不虚构批量张数、遮罩、种子或像素锁定功能。先查看本地编辑目标，再调用支持的图像编辑工具。

## 建立画风锚帧

```text
任务：把原 PV 的目标绘稿中的[人物]替换为[角色/形态]，输出一张动画绘稿。
图1：原片目标，负责镜头、人物位置/大小、裁切、姿势、表情及遮挡。
图2：角色身份，负责[刘海遮眼关系、发型/颜色、眼睛、主要服饰与饰品]。
图3：已选中的简化画风，负责线宽、色块、头身比和阴影层数。
保持：[具体构图、眼睛睁闭、嘴形、手势、出画边界]。
简化：[去除密集衣纹/材质高光，饰品保留主要轮廓，阴影限制为原PV的层数]。
本帧可见的区域只有[范围]；[被遮挡处]不可新画出脸/身体。
背景/歌词/特效将单独合成，本稿仅输出[人物层或指定完整画面]。
保持原PV的手绘平面感，不把角色精细立绘的渲染程度带入本稿。
输出：一张[画布比例/裁切要求]的干净图，不含分析线或标签。
```

角色设定可以决定发型和眼睛身份；当前原帧的睁闭眼/视线/嘴形必须逐项指定。不要统一使用“可爱微笑”。非对称刘海写清“角色自身哪侧 / 画面哪侧”，不用含糊的“左眼”。

## 原 A/B 交替稿的变化迁移

```text
图1：已通过的新角色 A，作为身份/画风/持续结构基准。
图2：原作 A。图3：原作 B，本次必须完成的姿势与表情目标。
图4：真实二维差值板，含 RGB 差值和旧蓝/新橙轮廓。
图5：[关键局部]放大，不是新画风。

从新角色 A 绘制新角色 B。保留[比例、发束身份、饰品、身体定位]。
迁移以下实际变化：
- 眼睑/眉毛/嘴：[明确状态或曲线改变]。
- 头发：[哪根发束、哪一段、朝哪里，幅度参照什么局部宽度]。
- 左/右肩袖、袖口：[两侧分别列出观察到的差异]。
- 衣摆/衣褶：[轮廓及内部线的改变]。
- 描边：[哪段变粗/重复压线，其他小范围手绘轮廓差异]。
不要只改头发或仅加随机抖动；不要大幅摇头/移动整个身体。
身份参考不覆盖原B的表情和姿势；差值板上的标记不进入成稿。
输出一张完整B，不输出差值图或多格图。
```

这里的幅度来自真实空间差值和局部尺度，不是用“总体变化 5%”替代。缩略图看似一样也可能包含重要的眨眼或手指变化。

## 相邻端点之间的过渡稿（adapted_motion）

```text
图1：已通过的前端点。图2：已通过的后端点。
图3：两端点的二维叠图与差值。图4：原作相关动作/风动变化。
绘制从前到后[运动阶段，例如起步/中点/回摆]的一张中间稿。
追踪[编号发束/袖边/衣摆]的同一连接关系。发根保持[位置]，
中段轻弯，末梢移动到[两个端点之间的可见区域/标记位置]。
发长和体积保持；不得换发型、镜像、消失后在另一边重现。
衣袖和衣摆也移到各自中间状态，允许轻微滞后；身体保持定位。
输出实线清楚的单张绘稿，不做双影、淡化或变形痕迹。
```

先对比实际结果：它是否复制了端点，是否越过了两端轮廓，是否把头发变短？不通过时不要因为文件名叫 `inbetween` 就把它放进时间轴。

模型混淆多图时，可对最近合适的单稿作局部编辑，保留已核定的空间目标。例如“现有四束长发下半段轻移到背部中央偏左，根部不动”，配局部位置图；避免“完全不变”与“所有地方都要动”的冲突。像素坐标必须基于当前输入实际尺寸，仍需查验，不能当作硬约束保证。

## 手、眼与语义修复

```text
编辑目标：图1。图2为原帧结构，图3为相邻已通过稿。
只修复[手/眼/发束/框内背景]的[具体错误]。
手：可见手指为[观察结果]，拇指位于[方位]，掌心朝[方向]，
指节/手腕/袖口连接应[说明]，[道具]遮住[区域]。
眼：保持角色虹膜/刘海身份，将睁闭与视线改为原帧的[状态]。
语义：[指定区域]是[头发/面板内部底色]，不是[误识别物]。
保持其他通过的区域和道具；输出与原编辑目标相同的完整画布。
```

可见手指数量由真实遮挡决定，不能每个姿势都硬要求五根全部露出。原道具已正确时，不要伴随手部修复无谓重画硬币或魔杖。
