# 比例、位置与姿态基准

用于建立角色锚帧、修复比例/定位、处理侧坐与躺姿，以及检查相邻镜头。它补充身份参考，不能覆盖原 PV 的动作和镜头语言。

## 建立能复用的项目基准

选取用户已认可且能代表本片的绘稿；缺少关键姿态时先做少量方案，不为已有合适基准重复征求确认。按实际镜头需要记录：

| 项目 | 记录与比较方式 |
| --- | --- |
| 头身与肩宽 | 头部尺寸、肩关节位置、躯干比例；区分肩膀、袖子与头发的外轮廓 |
| 腰与骨盆 | 躯干轴线、肋部到骨盆的自然连接、坐姿压缩与衣物垂落；不靠反复“加宽/变细”调出沙漏或鼓包 |
| 头发 | 发根分区、持续发束、长度参照到身体何处、体积与卷曲方向；区分透视缩短和真的剪短 |
| 服饰 | 领口、露肩边界、袖口、裙片、饰品位置及同一衣料长度 |
| 风格 | 线宽/压线、平涂与阴影层数、眼睛简化及色彩与整片的协调 |

测量建立在当前画布与可见结构上，可用头高等局部尺度辅助，不把一个角度的像素宽度强套给所有视角。保留用户选定稿 ID、适用视角和不可改变的身份特征。通用 skill 不固定某个角色的发量、眼睛颜色或身体比例。

## 先判断修什么

| 实际问题 | 优先操作 | 需要防止的回退 |
| --- | --- | --- |
| 绘稿已通过，只是整体偏高、偏大或偏左 | 对已分离角色层统一缩放、平移，必要时恢复它原来覆盖的背景 | 为定位重新生图导致脸、服饰或发束重置 |
| 头身、肩腰或肢体结构不对 | 原姿态 + 认可比例锚帧指导重绘 | 用非等比拉伸、局部网格捏形冒充解剖修复 |
| 侧坐画成正坐、侧躺画成站立发型 | 重建躯干/头部方向与遮挡，再按该方向重绘 | 仅旋转一张站姿头发，或只缩窄背影 |
| 发束突然消失、换边或衣服跳变 | 查看原作与新版相邻稿的二维差值，修复整组连接关系 | 静态截图好看但进入/离开时跳变 |

用户明确要求每关键稿生图时按要求执行；仍用现有基准限制编辑，并检查生图造成的附带变化。若缺少角色层、干净背景或可靠掩膜，先解决分层，不对带歌词/水印的整幅画面一起缩放。

## 相邻镜头的大小与位置

1. 先核对原片是否保持同一景别、拍摄方向和站位。仅在应连续的构图中做一致性配准；切到近景、人物转身、镜头运动应保留。
2. 在前段末帧、当前段首帧/末帧、后段首帧标出头顶、头部尺度、身体中心、脚部接触线和双脚中心。明确坐标基于哪张尺寸的画布；生成图换尺寸后重新换算。
3. 脚部锚点应来自实际脚/鞋区域或人工核定标记。总体 alpha 包围盒、最低一段像素、长裙/长发底缘都不能可靠代表脚底。坐姿使用座面接触、骨盆和手部支撑等适用锚点；脚被裁掉时不猜脚底。
4. 先等比缩放，再在选定锚点附近平移。记录实际变换、重采样和遮罩；同组变换须保留源绘稿之间的微小动作，不逐稿归一化成完全相同的包围盒。
5. 查阅叠图与包含前后转场的短片。测量值用于发现异常，不能单凭坐标接近宣称自然。

新角色头发更长或鞋型不同，外轮廓总高不一定等于身体高。约束可以同时涉及头部大小、身体位置和可见下肢；如果互相冲突，回到姿态/绘稿检查，不反复无根据地偏移。

## 姿态、重力与遮挡

- **背部侧坐**：头、肩线、骨盆和双腿应属于同一转向；透视中的远侧肩更受遮挡，不能补成对称宽背。发束可自然覆盖部分肩腰，但下面的躯干仍应合理；遮住错误不是结构修复的替代。
- **床面或平台侧躺**：以原片的头部倾斜、脸朝向和接触面为准。头发先沿接触面铺开，再从边缘悬垂；不要套用面向镜头的直立背发。
- **躺在水面**：头、躯干和肢体处于相容的透视；浮发沿水面散开，有长度、体积和发束连接，不是多根竖直落下的带子。水面遮挡、反射与原 PV 的简化表达一致。
- **眼与刘海**：先在脸部结构上确定眼眶和视线，再放刘海、手、玻璃等遮挡。写清角色自身左右与画面左右；不能为了露眼把眼睛移向脸缘，也不能无依据删掉原本可见的眼部。
- **玻璃/鱼缸**：根据原帧指定眼睛的可见局部、玻璃边界和折射偏移，保持低细节画风。折射不应变成移错整个眼眶；也不强求所有姿态都完整露出双眼。
- **脚与鞋**：先读清脚背/脚底、足尖方向、鞋跟及带子的透视和遮挡。鞋底纹样或凉鞋带不能被误画成多排脚趾；只呈现姿态实际可见的结构。

将本次姿态的关键约束与原片 A/B 二维差值一起送入生图。发量、服装结构与重力规则在相邻稿保持一致，微小飘动及描边变化按原稿迁移，不能因此把整组冻结。
