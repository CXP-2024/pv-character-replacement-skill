# PV 角色替换帧动画

把原 PV 的绘画语言、演出和曝光时间表迁移到新角色。目标是“同一段演出由另一个角色出演”，不是把精细立绘贴在原背景上。

## 先确定制作约定

从用户现有要求与项目文件提取：原片/制作区间、替换哪些人物、角色版本与形态、采用的画风样例、声音、输出规格、最近认可版本、允许的运动处理与检查强度。只询问会阻塞制作的缺失项；其余按已知偏好推进。

- 默认 `strict_source`：保留原片独立绘稿及曝光边界，不自动改成固定 A/B 交替，也不把每个视频帧都重新生成。
- 用户需要长发等部位平顺转向时，可用 `adapted_motion`：新增模型绘制的过渡稿，保持镜头总长和主要拍点，明确记录曝光变化。没有这项授权时，先用同样曝光下幅度合适的重绘解决；需要增加过渡再说明具体取舍。
- 默认逐稿结构检查、整组连续性检查和实际速度对比。用户明确要求“先并发生成一轮、不返修”时照做，标注未审定，不把草稿算作已通过。
- 角色绘画默认由可用生图工具完成。若环境有 `imagegen` skill，遵循它的工具/保存流程；工具缺失时直说限制，保留分析及任务清单，不以程序画图冒充生图结果。调用量、并发和返修预算按用户要求或任务规模安排。

## 1. 固定来源和角色基准

从同一份原片解码，记录画布、帧率/PTS、时长和声音；不用不同来源截图混合检测。可变帧率不能用平均帧率冒充原曝光表。

建立简短角色基准：正/侧/背视、脸和眼睛、手与袖口、主要饰品、轮廓与配色。检索资料时核对角色、版本及形态，区分官方设定、社区模型与二创，保存来源。用户提供的脸部参考优先解决身份细节，不自动提高全片渲染复杂度。

先用少量具有代表性的镜头确定原 PV 的简化程度：轮廓、头身比、色块、线宽、阴影层数、饰品密度。已有认可样例时直接复用其风格。身份特征要稳定，原立绘的所有细节不必搬进简笔 PV。

把已认可的比例与服饰记入项目基准，再推广批量；按本片实际出现的站姿、背影、侧坐或躺姿选择锚帧，不必另做无关姿势。头身比、肩宽、发长/发量和服装结构应有可对照的图示，不能只写“保持一致”。比例、位置或特殊视角任务先读 [references/proportions-and-placement.md](references/proportions-and-placement.md)。具体角色、眼睛配色方案和用户选定版本保存在项目配置中，不写成通用 skill 的固定角色设定。

## 2. 拆分语义与原片时间轴

分清人物绘稿变化、镜头变换和背景/歌词/粒子变化。每个镜头标出人物、衣物、道具、框内底色、遮挡物与特效的归属和层级；局部红色可能是头发，不能猜成桌面。

从制作阶段保留可复用的无字底图、文字与独立特效，记录文字位置、显示时间及变化，避免最后才从烧录字幕反推。需要无字版、素材包或逐字歌词时，按需读 [references/postproduction-and-lyric-timing.md](references/postproduction-and-lyric-timing.md)；用户没有要求时不额外制作交付包或运行音频模型。

逐帧检测仅产生候选，再查阅原图与空间差值确认。睁闭眼、细小手势、衣褶、轮廓和加重描边都可能是独立绘稿。只有差异接近压缩噪声，且关键局部没有连贯形状变化时才合并。不要凭全画面平均差异、稀疏采样或“这段大概只有两张”决定。严格阈值可能把同稿的压缩副本拆成很多候选，不能直接按候选数批量调用生图；先核定真实绘稿。

保存原帧/PTS → 绘稿 ID 的明确曝光表，包含单帧转场和循环回到开头。分析、差值工具和时间轴格式见 [references/analysis-and-timing.md](references/analysis-and-timing.md)。

## 3. 给每张参考分配职责

每次 prompt 明确这些不同职责，不笼统写“严格参考所有图片”：

| 参考 | 决定什么 |
| --- | --- |
| 原 PV 当前目标绘稿 | 镜头、裁切、姿势、表情、视线、可见范围与遮挡 |
| 新角色设定 | 身份、固有发型/发色、服装结构、辨识特征 |
| 同镜头已认可的新角色绘稿 | 简化画风、比例、色彩、持续存在的发束与饰品 |
| 原作前后绘稿的实际二维差值图 | 哪里变化、方向/幅度、描边与褶皱变化 |
| 前后相邻的新绘稿 | 长发/衣物的连续运动、遮挡与发束连接 |

差值参考至少包含原 A/B 并排、实际 RGB 差值放大和双色轮廓叠图；必要时补眼、手、袖口与发梢局部放大。数字只能筛选，不能代替二维图。独立字幕和粒子应另看或在人物检测中遮掉。

把变化逐项写进 prompt：眼睑/眉毛/嘴形、头发中段与发梢、两侧肩袖、袖口、衣摆、线条压力。已认可绘稿是连续性依据，不是冻结人物的模板。使用 [references/prompt-patterns.md](references/prompt-patterns.md) 中对应模板。

比例问题先区分身体姿态、衣料折叠与镜头缩放；下蹲不能把裙身整体压短。需要试长度时固定姿势出少量可辨方案，选定后核对站立→下蹲→回弹中的同一件衣服。具体约束见 [衣料与纯色检查](references/layers-and-continuity.md#衣料折叠与纯色检查)。

修复前先分类：已认可绘稿仅整体大小或位置不符时，优先对现有角色层做统一缩放和平移；解剖比例、发型结构、服饰或视角错误才重绘。不能用非等比拉伸修正身体，也不能为显示被挡住的眼睛而移动眼位。具体定位和遮挡规则见比例参考文件。

## 4. 按依赖批量生成

先完成身份和画风锚帧，再并发无依赖的镜头或关键姿势。相邻中间稿需要两个端点先就绪；不要把所有稿都从同一个极值母版独立生成。

复用实际重复的绘稿及其曝光，不复用表情/轮廓已经变化的帧。缓存通过的素材；局部修复只重新生成受影响的绘稿和合成区间；用户要求整帧时，每稿完整重绘，不生成小组件拼补。每次调用保存 prompt、参考顺序/职责、输出路径、采用或失败原因。

需要过渡时，用相邻端点、原片差值及新绘稿的空间叠图约束中间位置。检查模型是否真的画在两个端点之间；“写了 halfway”不等于得到中间稿。若反复复制某个端点，减少冲突参考，改用明确局部编辑，再回到整组检查。

## 5. 连续性与分层合成

连续性既不是每帧换发型，也不是永久固定朝一边。持续发束、发长、体积、饰品和遮挡关系应可追踪；发根较稳，中段位移较小，发梢可有滞后。长发不能机械照搬原角色短发的左右极值。衣袖和衣摆应响应同一股风，幅度/相位可以不同。检查循环末帧 → 首帧。

保留原背景、框线、歌词、道具和独立特效，按原时间轴分层合成。只替换需要改变的角色区域，不补画原构图外的脸、身体或手。优先限定区域和连通空背景掩膜，不能对全图相似颜色一删了之。细节见 [references/layers-and-continuity.md](references/layers-and-continuity.md)。

默认不以光流、网格形变、镜像、morph 或交叉淡化冒充新的人物绘稿；用户明确允许近似时，记录使用范围。正常裁切、统一画布及源镜头确有的整层平移缩放要与非刚性人物变形区分。不要声称它们能代替衣褶、手指或发束重绘。

## 6. 检查与交付

按 [references/review-and-delivery.md](references/review-and-delivery.md) 检查三个层次：单稿结构、相邻及循环连续性、实际速度的原版/新版对比。手部、眼睛、缺失背景与特效必须与原帧对照；技术解码成功不是美术验收。

每次局部修复检查“前一段 → 修复段 → 后一段”，循环再检查末稿接首稿。连续构图下核对头顶、头部大小、身体中心及实际脚部锚点，避免跨镜头忽然长高或横移；不能把长发/裙摆底缘当脚底，也不能消除原作有意的镜头变化。

提供左原版/右新版的聚焦片段与完整目标区间，循环问题另给完整循环预览。核对帧数或 PTS、时长、音轨、切镜头和结尾。修复以最近认可版为基线，保留其余部分，避免合成长片时回退旧稿。

区分生成候选、选定绘稿、预览和正式发布状态。用户仅要试版时保留正式文件；要求正式更新时，完成目标 MP4、相关素材及清单同步并验证后再报告“已更新”。检查实际交付编码和播放兼容性；说明无损母版检查、压缩成片检查与实际播放器检查各自覆盖的范围。版本与发布步骤见交付参考文件。

报告实际采用的绘稿数、曝光策略、检查范围和仍有差异。不要承诺 prompt 能精确锁住像素、空间差值必然被模型执行，或添加过渡后仍“逐帧曝光完全一致”。生成资产需保存到当前项目；仓库发布是独立操作，调用本 skill 不隐含上传原片、角色参考或个人文件。
